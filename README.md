# 智能无级调速风扇控制器（STM32F103C8T6）

基于 STM32F103C8T6 的环境监测与风扇控制节点：AHT20 采集温湿度，PWM 无级调速，
OLED 本地显示，双按键操作，并通过 USART1 以自定义帧协议与上位机通信。
代码按 **驱动层 / 业务层 / 调度层** 三层组织，主循环采用时间片分频调度，全程非阻塞。

---

## 功能特性

- **无级调速**：档位 0~100 映射到 PWM 占空比，启动时先以 100% 占空比突发 100 ms，保证电机可靠起转
- **温湿度采集**：AHT20（软件 I2C），每秒采集一次，数据以 ×10 整数形式处理，避免浮点开销
- **本地显示**：0.96" OLED（SSD1306，128×64），状态页与参数页两页切换，带显存缓冲、整屏刷新
- **按键交互**：双按键长短按识别——开关机 / 翻页 / 加减档
- **串口通信**：自定义帧协议（`0xAA 0x55` 帧头 + 长度 + 数据 + CRC8），每秒主动上报，同时接收控制指令
- **可靠性**：独立看门狗（IWDG）＋ 串口接收环形缓冲＋ CRC 校验
- **低功耗**：风扇停止且无按键活动时进入 STOP 模式，按键 EXTI 唤醒

## 硬件组成

| 器件 | 作用 |
|---|---|
| STM32F103C8T6 最小系统板 | 主控 |
| AHT20 | 温湿度传感器（3.3 V） |
| OLED 0.96"（SSD1306） | 本地显示 |
| 直流风扇 + S8050 三极管 | 低边驱动，5 V 供电 |
| 轻触按键 ×2 | 开关机 / 翻页、加减档 |
| ST-Link | SWD 烧录与调试 |

## 引脚分配

| 外设 | 引脚 | 说明 |
|---|---|---|
| 软件 I2C（OLED + AHT20 共用） | PB8 = SCL / PB9 = SDA | 器件地址 0x3C / 0x38 |
| 风扇 PWM | PA0 = TIM2_CH1 | 1 kΩ → S8050 基极 → 低边驱动 5 V 风扇 |
| KEY1 | PB1（上拉 + EXTI1） | 短按 = 开/关，长按 = OLED 切页 |
| KEY2 | PB11（上拉 + EXTI11） | 短按 = 加档，长按 = 减档 |
| USART1 | PA9 = TX / PA10 = RX | 115200，上报帧与调试输出 |
| SWD | PA13 / PA14 | ST-Link 烧录调试 |

## 软件架构

```
┌─────────────────────────────────────────────┐
│  user/      调度层：初始化、时间片分频、中断收口   │
├─────────────────────────────────────────────┤
│  app/       业务层：状态机、显示逻辑、协议解析     │
├─────────────────────────────────────────────┤
│  hardware/  驱动层：只负责"怎么读写硬件"          │
├─────────────────────────────────────────────┤
│  system/    基础设施：SysTick 延时与毫秒时钟      │
└─────────────────────────────────────────────┘
```

```
├── user/
│   ├── main.c              初始化 → 10 ms / 100 ms / 1 s 分频调度 → 低功耗

├── hardware/

│   ├── AHT20.c/h           温湿度驱动，整数 ×10 输出
│   ├── PWM.c/h             TIM2_CH1，1 kHz，占空比 0~100%
│   ├── Key.c/h             双按键长短按 + EXTI 唤醒
│   ├── USART.c/h           串口收发 + 接收环形缓冲
│   └── WDG.c/h             独立看门狗 IWDG
├── app/
│   ├── app_fan.c/h         风扇状态机：关/运行、档位↔占空比、启动突发
│   ├── app_display.c/h     OLED 业务：状态页 / 参数页
│   ├── app_sensor.c/h      每秒采集温湿度
│   └── app_protocol.c/h    自定义帧协议，组帧/解析与 CRC8
└── system/
    └── Delay.c/h           基于 SysTick 的 ms 延时与全局毫秒时钟
```

### 时间片调度

主循环不使用阻塞延时，而是按 10 ms / 100 ms / 1 s 三个节拍分频执行：
10 ms 处理按键扫描，100 ms 刷新显示并喂狗，1 s 采集传感器并上报一帧。

## 串口协议

上行数据帧：

| 字节 | 内容 |
|---|---|
| [0] | `0xAA` 帧头 1 |
| [1] | `0x55` 帧头 2 |
| [2] | `len` 数据段长度 |
| [3..3+len-1] | 数据段 |
| [N] | CRC8（从 `len` 字节算到帧尾） |

上报数据段（`len = 6`）：

| 偏移 | 内容 |
|---|---|
| [0] | 运行状态：0 = 关机，1 = 运行 |
| [1] | 档位：0~100 |
| [2..3] | 温度 ×10，高字节在前 |
| [4..5] | 湿度 ×10，高字节在前 |

下行控制指令帧（同协议，数据段 [0] 为命令码）：

| 命令码 | 含义 |
|---|---|
| `0x01` | 设置档位，[1] = 目标档位 |
| `0x02` | 开关机，[1] = 0 关 / 1 开 |

## 编译与烧录

本项目只包含应用源码，**不包含** STM32 标准外设库（StdPeriph Library）与启动文件，
需要基于自己的 STM32F103 工程模板编译。

1. 用 STM32F103C8T6 工程模板新建工程（含 `start/`、`library/` 库文件）；
2. 把 `hardware/`、`app/`、`system/` 下的 `.c/.h` 加入工程对应的 Groups；
3. 用本项目的 `user/main.c`、`user/stm32f10x_it.c` 作为程序入口；
4. Options → C/C++ → Include Paths 包含 `start`、`library`、`user`、`hardware`、`app`、`system` 六个目录；
5. Options → Target → 勾选 **Use MicroLIB**（`printf` 重定向需要）；
6. 编译后通过 ST-Link 以 SWD 方式下载。

> **OLED 字体**：仓库内使用精简字库（大写字母、数字与少量符号）。需要显示中文时，
> 替换为自己的 `OLED_Font.h` 全字符库即可，`OLED.c` 的调用方式不变。

> **低功耗调试**：`main.c` 中 `ENABLE_LOWPOWER` 为 0 时跳过 STOP 模式。
> 建议先完成全部功能调试，再将其置 1；否则调试器在低功耗下容易断开。

> **AHT20 与 OLED 必须用 3.3 V**，不要接入 5 V 电源轨。

## 设计要点

| 要点 | 实现方式 |
|---|---|
| 分层解耦 | 驱动层只管读写硬件，业务层只管逻辑，调度层只管时序 |
| 非阻塞 | 所有等待改为节拍分频，主循环不出现 `delay_ms` 死等 |
| 状态机 | 风扇 关/运行 两态 + 启动突发子状态 |
| 显示不闪烁 | 显存缓冲 + 整屏一次性刷新，避免逐字节写总线 |
| 总线复用 | 软件 I2C 抽为公共模块，OLED 与 AHT20 共用 |
| 通信可靠 | 帧头 + 长度 + CRC8 查表校验，组帧与解析分离 |
| 抗干扰 | IWDG 看门狗，主循环按时喂狗 |
| 数据共享安全 | ISR 与主循环共享的标志、时钟均使用 `volatile` |
